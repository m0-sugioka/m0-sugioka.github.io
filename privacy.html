プライバシーポリシー

最終更新：2026年10月27日

このポリシーは、個人用生活支援システムJARVISのGoogle Calendar連携と、それに関連する案内機能での情報の扱いを説明します。

1. アクセスする情報と目的

本人が許可したGoogleカレンダーについて、カレンダーの識別情報、予定の識別情報・件名・開始終了日時・場所など、予定の取得や操作に必要な情報を扱います。目的は予定案内、移動・出発時刻の準備、および本人が確認した予定の追加・変更・削除です。

現在のOAuth設定は、Google Calendarの読み取り・変更を含む権限を要求します。そのうえで、アプリ内の設定と本人の確認によって、実際に操作する対象と内容を制限します。

予定の説明欄に場所を示す情報が含まれる場合、移動案内のために参照することがあります。自動の今日・明日の予定コンテキスト生成では説明欄全文をAIへ渡さず、予約番号・電話番号・チケット情報を案内用データから除外します。一方、個別予定を取得してAIで回答する経路では、説明欄などを含む取得結果がAIに渡る場合があります。すべての経路で説明欄が除外されるものではありません。

2. 保存する情報

Googleへのアクセスを継続するためのOAuthトークン、予定案内用のキャッシュ、関連する設定や会話記録は、利用環境のPC・端末に保存される場合があります。会話記録には予定に関する発話や返答が含まれることがあります。

この公開Webサイトや公開リポジトリに、実際の予定、会話記録、OAuthトークン、APIキーを掲載することはありません。

3. 外部サービスへの送信

  • Google：認証とCalendar APIを使った予定の取得・操作に必要な通信を行います。
  • Google Mapsなどの地図・経路サービス：移動案内が必要な場合、住所・位置情報・駅名・施設名などを送信することがあります。映画館名から目的地を確認する場合があります。
  • 設定された生成AIサービス：会話や依頼の理解・回答生成のため、発話、会話の文脈、必要なツール結果を送信することがあります。現在の通常会話はOpenAI APIを利用します。

各外部サービスの処理・保持条件は、そのサービスのポリシーと利用環境の設定にも従います。JARVISは、Googleユーザーデータを販売したり、広告配信や汎用AIモデルの学習を目的として利用したりしません。

JARVISによるGoogle APIから受け取った情報の利用と他のアプリへの転送は、Google API Services User Data Policy（Limited Useの要件を含む）に従います。

4. 保存期間・削除・アクセスの取り消し

保存データは、利用環境で機能を提供するために保持します。すべての記録を一定日数で自動削除する仕組みは前提にしていません。利用者本人または管理者が、該当するローカル記録・キャッシュ・トークンと、管理下にあるバックアップを確認して削除します。外部サービスに保存された情報は、そのサービスの手順に従います。

Googleへの今後のアクセスは、Googleアカウントの接続管理からJARVISの接続を取り消すことで停止できます。接続の取り消しだけでは、すでにPC・端末へ保存された記録は削除されません。JARVISの記録の削除と、Googleカレンダー上の予定の削除は別の操作です。

5. この公開Webサイトについて

このサイトはGitHub Pagesで配信する静的な説明ページです。フォーム、Googleログイン、独自のアクセス解析スクリプト、マイク・位置情報の取得機能は設けていません。配信に伴うアクセス情報は、GitHubのプライバシーポリシーに従って処理される場合があります。
